contextura-core: schemas

JSON Schemas of the open standard contextura-core. The specification and the source are at github.com/bijdt/contextura-core.

Version 0.18

  • app/3.json: App manifest: app.json in the repo of a project, with the gallery
  • brain/2.json: Brain settings
  • bundles/1.json: Bundles of the brain
  • documentation/1.json: Documentation registry
  • kit/3.json: Kit: apps/<id>.yaml, with the view floorplan
  • kit-data/1.json: Kit data: apps/<id>.data.yaml
  • metrics/1.json: Metrics of the brain
  • note/3.json: Note frontmatter
  • projects/1.json: projects.json, the registry of a workspace
  • readers/1.json: Readers of the brain
  • tile/2.json: Tile: what the command of a project prints on stdout, with button and input
  • twin/3.json: Feed your twin

Version 0.15 to 0.17

  • app/2.json: App manifest: app.json in the repo of a project (0.15 to 0.17)
  • kit/2.json: Kit: apps/<id>.yaml, with the sources notes and connection (0.16 and 0.17)
  • kit/1.json: Kit: apps/<id>.yaml (0.15)
  • tile/1.json: Tile: what the command of a project prints on stdout (0.15)

Version 0.14 and earlier (Dutch names)

  • app/1.json: Contextura app-manifest: app.json in de repo van een project
  • bouwdoos-gegevens/1.json: Contextura Bouwdoos: apps/<id>.gegevens.yaml
  • bouwdoos/1.json: Contextura Bouwdoos: apps/<id>.yaml
  • brain/1.json: Instellingen van de brain
  • bundels/1.json: Bundels van de brain
  • bundels/2.json: Bundels van de brain, ook data
  • documentatie/1.json: Register van de documentatie
  • lezers/1.json: Lezers van de brain
  • metingen/1.json: Meetgetallen van de brain
  • note/1.json: Notitie-frontmatter
  • note/2.json: Notitie-frontmatter, met ervaring
  • projecten/1.json: projecten.json (register v1 en v2)
  • tegel/1.json: Contextura tegel: wat de opdracht van een project op stdout levert
  • twin/1.json: Voed je twin
  • twin/2.json: Voed je twin, met vertel, laad op en los op
